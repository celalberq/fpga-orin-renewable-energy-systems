Goal
----

Show that the network/dashboard layer can carry higher-level tracker telemetry,
not only raw solar voltage/current/power.

Packet source
-------------

```text
Orin software tracker
  -> UDP JSON
  -> PC dashboard
```

Extra fields displayed
----------------------

```text

tracker.sun_pan_deg
tracker.sun_tilt_deg
tracker.track_error_deg
tracker.lr_error
tracker.tb_error
tracker.servo_enabled
```

Run PC dashboard
----------------

```text
cd "<repository-root>"
python network-telemetry-dashboard/code/pc_app/solar_live_dashboard.py --udp-host 0.0.0.0 --udp-port 5011 --http-host 127.0.0.1 --http-port 8085 --bess-load-w 0.1
```

Run Orin software tracker
-------------------------

```text
cd /home/msi
python3 solar-tracker-bess/code/orin_app/tracker_softloop_udp_gateway.py --udp-host PC_IP_ADDRESS --udp-port 5011
```

Expected result
---------------

```text
Dashboard link becomes healthy.
Tracker State changes between seeking and locked.
Panel Angles move toward Light Direction.
Tracking Error decreases after each virtual sun movement.
CSV log includes tracker columns.
```
