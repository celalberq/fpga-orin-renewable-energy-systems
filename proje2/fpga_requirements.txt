FPGA Requirements: proje2 Network
=================================

Required:

```text
1. At least 1 Ethernet port for monitor mode.
2. Ethernet MAC/PHY support with usable examples.
3. Enough block RAM for receive FIFOs and metadata buffers.
4. UART/SPI or Ethernet telemetry link to Orin.
5. Stable clocking for Ethernet interface.
```

Preferred:

```text
1. 2 Ethernet ports or SFP for inline mode.
2. Gigabit Ethernet rather than only 100 Mbps.
3. External DDR/SRAM for larger flow tables.
4. Open-source or vendor packet-processing examples.
5. Enough logic for parser, counters, rule engine, and telemetry.
```

FPGA selection pressure:

This is probably the strongest FPGA selector among the three projects. If a board cannot support Ethernet cleanly, it should not be the final common FPGA board.

Minimum practical board target:

```text
1x Ethernet: acceptable for monitor mode
2x Ethernet or SFP: preferred for final portfolio
50k+ logic cells: preferred
External memory: preferred
Good Ethernet examples: required
```
