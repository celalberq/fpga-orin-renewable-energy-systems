Proje2 Network Test 04: Telemetry Link Health Dashboard

Status

```text
SMOKE PASS / READY FOR LIVE TEST
```

Goal
----

Add communication reliability status to the same solar+BESS dashboard.

This connects the proje1 digital communication story to the integrated
renewable/network dashboard.

Data path
---------

```text
Nexys Video p3 packet
  -> checksum validation in UDP gateway
  -> sequence/gap tracking in dashboard
  -> link health panel
```

Run dashboard
-------------

```text
cd "C:\Users\Msi\Documents\yaz proje"
python proje2/code/pc_app/solar_live_dashboard.py --udp-host 127.0.0.1 --udp-port 5010 --http-host 127.0.0.1 --http-port 8084 --bess-capacity-wh 50 --bess-initial-soc 55 --bess-load-w 10
```

Open:

```text
http://127.0.0.1:8084
```

Run gateway
-----------

```text
cd "C:\Users\Msi\Documents\yaz proje"
python proje2/code/pc_app/solar_telemetry_udp_gateway.py --port COM6 --baud 115200 --udp-host 127.0.0.1 --udp-port 5010
```

Dashboard additions
-------------------

```text
Link State:
  healthy / warning / stale / waiting

Packet Rate:
  estimated received packet rate in Hz

Valid Packets:
  packets passing checksum and sequence validation

Invalid Packets:
  packets failing validation

Sequence Gaps:
  detected missing packet count
```
