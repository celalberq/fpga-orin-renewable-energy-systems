Proje2 Network Test 03: BESS SoC Dashboard Simulation
=====================================================

Status
------

```text
SMOKE PASS / READY FOR LIVE TEST
```

Goal
----

Add a battery energy storage system simulation to the live solar dashboard.

This strengthens the project from a solar telemetry demo into a solar+BESS
monitoring demo.

The next hardware stage keeps this same dashboard idea but replaces the simulated
BESS values with measured battery/storage telemetry from the FPGA packet.

Data path
---------

```text
Nexys Video auto-MPPT p3 packet
  -> COM6 UART
  -> UDP gateway
  -> dashboard
  -> BESS SoC simulation
```

What runs where
---------------

```text
FPGA:
  PWM
  auto MPPT perturb/reverse logic
  simulated PV voltage/current/power
  compact p3 telemetry packet

PC now / Orin later:
  UDP network receiver
  dashboard
  BESS state-of-charge calculation
  charge/discharge state
  CSV logging
```

BESS model
----------

```text
solar_w = p_mw / 1000
net_w = solar_w - simulated_load_w

if net_w > 0:
  battery is charging

if net_w < 0:
  battery is discharging

SoC is updated by integrating net battery power over time.
```

Pass condition
--------------

```text
1. Dashboard shows BESS SoC.
2. Dashboard shows battery power.
3. Dashboard shows simulated load.
4. BESS State changes between charging, discharging, and idle as solar power crosses the load.
5. Amber SoC trace appears on the chart.
6. CSV log includes BESS fields.
7. Solar power is shown on its own auto-scaled chart.
8. Duty and BESS SoC are shown together on a fixed 0-100% chart.
```

Measured storage upgrade path
-----------------------------

```text
Now:
  PV telemetry comes from Nexys Video.
  BESS SoC is simulated in the dashboard.

Next:
  Battery voltage/current are measured through MCP3208/INA226.
  FPGA sends battery fields with the PV packet.
  Dashboard shows measured storage state.
  Network layer logs a more diverse energy-system report.
```

This gives proje2 a stronger networking role because it transports and validates
the full renewable station state, not just one sensor stream.
