Proje2 Network Test 01: Solar Telemetry UDP Gateway
===================================================

Status
------

```text
LIVE PASS
```

Goal
----

Move from isolated board tests to an integrated system demo.

This test takes the working proje3 solar telemetry packet, validates it on the PC,
wraps it as UDP JSON, and logs it as proje2 network telemetry.

Why this speeds up the actual project
-------------------------------------

```text
Before:
  proje3 solar packet works
  proje1 communication tests work
  proje2 only has a stored frame parser

Now:
  live solar packet -> PC/Orin-style gateway -> UDP network stream -> network log
```

Network scripts
---------------

```text
Gateway:
  proje2/code/pc_app/solar_telemetry_udp_gateway.py

Receiver:
  proje2/code/pc_app/solar_telemetry_udp_receiver.py
```

Run with live Nexys Video telemetry
-----------------------------------

Terminal 1:

```text
cd "C:\Users\Msi\Documents\yaz proje"
python proje2/code/pc_app/solar_telemetry_udp_receiver.py --bind-host 127.0.0.1 --bind-port 5005
```

Terminal 2:

```text
cd "C:\Users\Msi\Documents\yaz proje"
python proje2/code/pc_app/solar_telemetry_udp_gateway.py --port COM6 --baud 115200 --udp-host 127.0.0.1 --udp-port 5005
```

Run without the board
---------------------

```text
cd "C:\Users\Msi\Documents\yaz proje"
python proje2/code/pc_app/solar_telemetry_udp_gateway.py --line "p3,seq=00001,d_pct=00050,v_mv=14560,i_ma=01268,p_mw=18462,mppt=up,f=0,chk=CC,raw=80" --no-send --max-lines 1
```

Expected gateway output
-----------------------

```text
OK udp->127.0.0.1:5005 p3,seq=00001,d_pct=00050,v_mv=14560,i_ma=01268,p_mw=18462,mppt=up,f=0,chk=CC,raw=80
```

Expected receiver output
------------------------

```text
OK from=127.0.0.1:<port> seq=1 p_mw=18462
```

Output logs
-----------

```text
proje2/data/solar_udp_gateway_log.csv
proje2/data/solar_udp_receiver_log.csv
```

Pass condition
--------------

```text
1. Receiver starts and listens on UDP port 5005.
2. Gateway reads the same p3 packet format already used by proje3.
3. Gateway checksum validation says OK.
4. Receiver prints seq and p_mw.
5. Both CSV logs are created.
```
