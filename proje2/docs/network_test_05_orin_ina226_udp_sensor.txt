Proje2 Network Test 05: Orin INA226 UDP Sensor Feed
===================================================

Status
------

```text
READY FOR LIVE TEST
```

Goal
----

Receive real solar voltage/current/power readings from the Orin over UDP and
show them on the existing live dashboard.

Data path
---------

```text
Solar panel
  -> INA226 current/power sensor
  -> Orin Nano Super I2C bus 7, address 0x44
  -> UDP JSON packet
  -> proje2 dashboard/logging
```

Run dashboard
-------------

```text
cd "C:\Users\Msi\Documents\yaz proje"
python proje2/code/pc_app/solar_live_dashboard.py --udp-host 0.0.0.0 --udp-port 5011 --http-host 127.0.0.1 --http-port 8085 --bess-capacity-wh 50 --bess-initial-soc 55 --bess-load-w 0.1
```

Run Orin sender
---------------

```text
cd /home/msi
python3 proje3/code/orin_app/ina226_udp_gateway.py --bus 7 --addr 0x44 --shunt-ohms 0.1 --udp-host PC_IP_ADDRESS --udp-port 5011
```

Expected result
---------------

```text
Dashboard source: Orin INA226 real solar sensor
Link state: healthy
Power/voltage/current update once per second
Small sensor-only power readings are displayed in mW
CSV logs are written on both sender and dashboard side
```
