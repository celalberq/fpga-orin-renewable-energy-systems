Project title:

FPGA-Accelerated Network Telemetry and AI Anomaly Detection Appliance

Original main goal:

Create an edge network device where the FPGA extracts packet and flow metadata in real time while the Orin Nano Super performs anomaly detection, visualization, and logging.

Original target architecture:

Monitor mode MVP:

```text
Client/server traffic
  -> managed switch mirror port
  -> FPGA Ethernet input
  -> packet parser and counters
  -> metadata stream
  -> Orin Nano dashboard and anomaly detector
```

Inline mode extension:

```text
Ethernet in
  -> FPGA parser and rule engine
  -> Ethernet out
  -> Orin Nano control plane and AI analytics
```

Original planned FPGA role:

```text
1. Receive Ethernet frames.
2. Parse Ethernet, IPv4, TCP, UDP, and ICMP headers.
3. Count packets, bytes, protocol types, and flows.
4. Extract source/destination IPs and ports.
5. Apply simple rule flags.
6. Stream compact metadata to Orin.
```

Original planned Orin Nano role:

```text
1. Dashboard for packet rates, top flows, and alerts.
2. Anomaly detection from FPGA metadata.
3. Dataset logging for normal and abnormal traffic.
4. Experiment automation with iperf3, ping, and scripted traffic.
```

Original MVP scope:

```text
1. Monitor mode with one Ethernet input.
2. No packet forwarding at first.
3. Parse metadata and display it live.
4. Detect traffic bursts, scans, and unusual protocol patterns.
```

Original success metrics:

```text
1. FPGA receives traffic from a mirror port.
2. FPGA extracts header metadata.
3. Orin dashboard shows live packet and flow statistics.
4. At least three traffic patterns are tested: normal, scan, flood/burst.
5. AI or rule-based anomaly alert is generated.
```
