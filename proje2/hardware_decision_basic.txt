Hardware Decision: proje2 Network
=================================

Current decision:

Buy network hardware only when the parser/metadata design starts moving from simulation to live traffic.

Needed now:

```text
1. Nexys Video
2. Laptop/PC
3. USB programming cable, included with Nexys Video kit
4. Nexys Video 12V supply, included with kit
5. At least one Ethernet cable
```

Buy for live network experiments:

```text
1. Managed gigabit switch with port mirroring
   Recommended type: TP-Link TL-SG105E or TL-SG108E
   Why: port mirroring lets the FPGA monitor traffic without being inline.

2. Ethernet cables
   Buy at least 3:
     - PC to switch
     - router/server to switch
     - switch mirror port to Nexys Video

3. USB-to-Ethernet adapter
   Optional, only if the laptop/PC has no Ethernet port.
```

Do not buy yet:

```text
1. SFP modules
2. Fiber/DAC cables
3. Enterprise managed switch
4. Network TAP
```

Why this is enough:

```text
The Nexys Video already has a Gigabit Ethernet PHY.
A small smart switch with port mirroring is enough for the first monitor-mode project.
```

Source note:

TP-Link lists TL-SG105E as a 5-port gigabit Easy Smart switch with web management and port mirroring.

Source:

```text
https://www.tp-link.com/us/business-networking/easy-smart-switch/tl-sg105e/
```
