Goal
----

Add the Orin camera/computer-vision layer without disturbing the working
mounted-panel servo tracker:

```text
CSI or USB camera
  -> bright light target detection
  -> estimated pan/tilt target
  -> UDP tracker telemetry with vision fields
  -> fpga-digital-communications CRC/QPSK/OFDM bridge
  -> network-telemetry-dashboard dashboard vision row
```

Why This Matters
----------------

```text
The project is no longer only a scripted/software tracker.
The Orin starts doing useful computer-vision work:
  detecting a light source,
  estimating target direction,
  reporting confidence,
  and preparing for camera-guided servo tracking.

This strengthens the CV/computer engineering side while keeping renewable
energy as the main system domain.
```

```text

Do not drive servos in this test until camera detection is clearly stable.
```

Known behavior:

```text
The target was near the camera edge, so the controller saturated at safe servo
limits around pan=70 deg and tilt=100 deg. This is acceptable for a first live
CV+servo pass. The next run should place the light closer to the camera center
or use wider safe limits only after checking the mechanism has clearance.

The dashboard can show stale after the finite --max-packets run ends. This is
not a packet-quality failure if the bridge and dashboard show zero bad packets
and zero gaps during the active run.
```

USB Camera Tuning Pass
----------------------

The USB camera was also detected and confirmed working as a convenient tuning
camera:

```text
UVC Camera (046d:081b)
  /dev/video1
  /dev/video2
```

Use `--camera usb --camera-id 1` for the USB camera. It can sit on a stand for
detection and command-direction tuning. For genuine closed-loop servo tracking,
rigidly attach it to the moving pan platform so camera error changes when the
servo corrects the panel angle. Keep the CSI camera as the final onboard option.

The tracker script now supports per-axis tuning:

```text
--pan-gain
--tilt-gain
--invert-x
--invert-y
--disable-pan
--disable-tilt
```

These flags allow pan and tilt to be calibrated separately, especially when the
left-right axis works but the up-down axis is weak or mechanically constrained.
