Solar Tracker and BESS PC Parser/Logger V1
==========================

Goal
----

Read shared telemetry packet v1 from the Nexys Video UART port, parse the fields,
check sequence behavior, compute a PC-side checksum, and log CSV rows.

Script
------

```text
solar-tracker-bess/code/pc_app/solar_packet_logger.py
```

Command
-------

```text
python solar-tracker-bess/code/pc_app/solar_packet_logger.py --port COM6 --baud 115200 --log solar-tracker-bess/data/solar_packet_v1_log.csv
```

List ports:

```text
python solar-tracker-bess/code/pc_app/solar_packet_logger.py --list-ports
```

Input packet
------------

```text
p3,seq=00001,d_pct=00050,v_mv=14560,i_ma=01268,p_mw=18462,mppt=up,f=0,chk=CC,raw=80
```

Important checksum note
-----------------------

```text
The FPGA v1 checksum includes raw duty.
The packet now prints raw=XX, so the PC logger can validate chk for all switch states.
```

Why this matters
----------------

```text
This parser/logger becomes the temporary PC version of the future Orin telemetry service.
It is also the base for:
  fpga-digital-communications communication reliability checks
  network-telemetry-dashboard network logging and packet monitoring
```
