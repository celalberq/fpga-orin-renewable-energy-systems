Solar Tracker and BESS Board Test 09: PCA9685 Servo Control from Orin I2C
=========================================================

Status
------

```text
READY FOR LIVE TEST
```

Goal
----

Bring up the solar-tracking actuator path:

```text
Orin Nano Super -> I2C -> PCA9685 -> MG90S servo -> panel angle
```

This is the movement/control half of the renewable project. The INA226 already
proved real voltage/current/power sensing; this test proves Orin can command a
servo angle safely.

Orin 40-pin header wiring
-------------------------

Logic wiring:

```text
Orin pin 1  3.3V -> PCA9685 VCC
Orin pin 6  GND  -> PCA9685 GND
Orin pin 3  SDA  -> PCA9685 SDA
Orin pin 5  SCL  -> PCA9685 SCL
```

External servo power
--------------------

Use the separate 5V adapter for servo motor power:

```text
5V adapter + -> PCA9685 V+
5V adapter - -> PCA9685 GND
```

Important safety notes:

```text
PCA9685 VCC is logic power and should be 3.3V from Orin.
PCA9685 V+ is servo motor power and should be 5V from the adapter.
Orin GND, PCA9685 GND, and 5V adapter GND must be connected together.
Do not power the MG90S servo from Orin 3.3V.
Do not connect 5V adapter + to Orin 3.3V.
```

Servo connector on PCA9685 channel 0
------------------------------------

For a normal MG90S-style connector:

```text
Brown/black wire -> GND row
Red wire         -> V+ row
Orange/yellow    -> PWM signal row
```

I2C detection
-------------

Run on Orin:

```text
sudo i2cdetect -y -r 7
```

Expected:

```text
0x40 = PCA9685 main address
0x70 = PCA9685 all-call address
```

First neutral-angle command
---------------------------

```text
cd /home/msi
python3 solar-tracker-bess/code/orin_app/pca9685_servo_test.py --bus 7 --addr 0x40 --channel 0 --angle 90
```

Expected:

```text
Servo moves to or holds near center.
No Orin reset.
No cable heating.
No servo buzzing violently.
```

Safe small sweep
----------------

Start with a small range before mounting the panel:

```text
python3 solar-tracker-bess/code/orin_app/pca9685_servo_test.py --bus 7 --addr 0x40 --channel 0 --sweep --min-angle 60 --max-angle 120 --step 10 --cycles 1
```

If the servo moves correctly, later use wider motion:

```text
python3 solar-tracker-bess/code/orin_app/pca9685_servo_test.py --bus 7 --addr 0x40 --channel 0 --sweep --min-angle 30 --max-angle 150 --step 10 --cycles 1
```

Why this matters
----------------

```text
INA226 provides measured power.
LDR/camera can estimate sun direction.
PCA9685 + servos can change panel angle.
The dashboard/network path can report sensor state, actuator state, and link health.
```
