Solar Tracker and BESS Board Test 08: Orin INA226 UDP Dashboard Feed
====================================================

Status
------

```text
READY FOR LIVE TEST
```

Goal
----

Send real INA226 solar voltage/current/power readings from the Orin to the
same UDP dashboard used by the network project.

This makes the project architecture clearer:

```text
Solar panel -> INA226 -> Orin I2C -> UDP -> dashboard/logging
Nexys Video -> MCP3208/UART -> UDP -> dashboard/logging
```

What this proves
----------------

```text
solar-tracker-bess: real renewable sensing
network-telemetry-dashboard: real network telemetry transport
fpga-digital-communications: packet validation layer can be reused around this data later
```

Run dashboard
-------------

On the PC or Orin where the browser dashboard should run:

```text
cd "<repository-root>"
python network-telemetry-dashboard/code/pc_app/solar_live_dashboard.py --udp-host 0.0.0.0 --udp-port 5011 --http-host 127.0.0.1 --http-port 8085 --bess-capacity-wh 50 --bess-initial-soc 55 --bess-load-w 0.1
```

Open:

```text
http://127.0.0.1:8085
```

Run Orin INA226 UDP gateway
---------------------------

On the Orin, from the copied project folder:

```text
cd /home/msi
python3 solar-tracker-bess/code/orin_app/ina226_udp_gateway.py --bus 7 --addr 0x44 --shunt-ohms 0.1 --udp-host 127.0.0.1 --udp-port 5011
```

If the dashboard is running on the Windows PC, replace `127.0.0.1` with the
Windows PC IP address on the same network:

```text
python3 solar-tracker-bess/code/orin_app/ina226_udp_gateway.py --bus 7 --addr 0x44 --shunt-ohms 0.1 --udp-host PC_IP_ADDRESS --udp-port 5011
```

Expected dashboard behavior
---------------------------

```text
Source shows: Orin INA226 real solar sensor
Voltage changes with light level
Current changes when panel load/light changes
Power becomes nonzero under strong enough light
Link State should become healthy
Small indoor/phone-light power is displayed in mW instead of rounded to 0.00 W
```
