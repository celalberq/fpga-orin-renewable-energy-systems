Current Hardware State
----------------------

```text
Solar panel:
  Mounted on cardboard adapter/base.
  Stabilized with 4-5 elastic bands.
  Prototype mount works.

Servo map:
  pan  = PCA9685 channel 15, left/right axis
  tilt = PCA9685 channel 12, up/down axis

Safe motion limits:
  pan  70-110 deg
  tilt 80-100 deg

I2C:
  Orin bus 7
  PCA9685 address 0x40
  INA226 address 0x44
```

Connections
-----------

```text
Orin pin 1  3.3V -> PCA9685 VCC -> INA226 VCC
Orin pin 6  GND  -> PCA9685 GND -> INA226 GND
Orin pin 3  SDA  -> PCA9685 SDA -> INA226 SDA
Orin pin 5  SCL  -> PCA9685 SCL -> INA226 SCL

5V 2A adapter + -> PCA9685 servo V+ / screw terminal V+
5V 2A adapter - -> PCA9685 servo GND / screw terminal GND

Important:
  Orin/PCA9685/INA226 grounds must be common.
  Do not connect adapter +5V to Orin 5V.
  Leave slack in panel and servo wires before moving.
```
