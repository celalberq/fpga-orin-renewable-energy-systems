Goal
----

Prove that the renewable-energy tracker is no longer software-only:

```text
Orin tracker loop
  -> PCA9685 I2C servo driver
  -> pan/tilt servos
  -> UDP tracker telemetry
```

Current Channel Map
-------------------

```text
PCA9685 address: 0x40
PCA9685 bus: 7

Pan servo:
  channel 15
  left/right rotation
  safe range 70-110 deg

Tilt servo:
  channel 12
  up/down rotation
  safe range 80-100 deg
```

Working Command
---------------

Use this for a visible real-servo tracker run:

```bash
cd /home/msi
python3 solar-tracker-bess/code/orin_app/tracker_softloop_udp_gateway.py --udp-host 192.168.1.219 --udp-port 5013 --max-packets 60 --interval 0.25 --control-gain 35 --lock-error-deg 10 --ina-enable --ina-bus 7 --ina-addr 0x44 --shunt-ohms 0.1 --drive-servos --pca-bus 7 --pca-addr 0x40 --pan-channel 15 --tilt-channel 12 --pan-min 70 --pan-max 110 --tilt-min 80 --tilt-max 100
```

What This Proves
----------------

```text
solar-tracker-bess now has a real actuator path:
  Orin computes tracker movement.
  PCA9685 receives I2C commands.
  Physical pan/tilt servos move.
  A real solar panel is mounted on the moving structure.
  Tracker state is still sent over UDP for network-telemetry-dashboard/fpga-digital-communications integration.
```
