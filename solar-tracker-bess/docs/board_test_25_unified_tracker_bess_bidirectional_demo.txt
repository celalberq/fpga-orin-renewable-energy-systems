Solar Tracker and BESS Board Test 25: Unified Tracker and Bidirectional BESS Demo
=================================================================

Date
----

2026-08-11

Purpose
-------

Validate one uninterrupted run in which the real tracker, signed BESS
telemetry, communication bridge, network dashboard, and CSV logging remain
active while the battery path transitions through idle, charging, idle,
discharging, and final idle states.

Safety conditions
-----------------

```text
TP4056 USB-C and the fan load were never connected simultaneously.
The fan was disconnected before USB-C charging.
USB-C was disconnected before the fan discharge path was connected.
MT3608 remained disconnected.
Orin and Nexys used their normal external supplies.
The run remained supervised throughout.
```

Continuous state sequence
-------------------------

```text
seq 000-156: idle
seq 157-198: charging
seq 199:     idle transition
seq 200-201: charging contact transition
seq 202:     idle transition
seq 203-335: discharging
seq 336-367: final idle
```

When both USB-C and the fan path were initially open, the INA226 bus-voltage
register observed the open monitored path rather than a valid cell terminal
voltage. Idle classification remained valid because signed current was near
zero. The final idle phase restored a valid approximately 3.50 V cell reading.
