=================================================

Status
------

```text
LIVE PASS
```

Goal
----

Move from manual switch-controlled telemetry to an FPGA-owned MPPT control loop.

The FPGA now:

```text
1. Generates PWM duty internally.
2. Simulates a PV power curve around a switch-selected maximum-power point.
3. Compares current power with previous power.
4. Keeps or reverses the perturb direction.
5. Streams the same p3 telemetry packet to the existing UDP dashboard.
```

Switch meaning
--------------

```text
SW0-SW2:
  Simulated maximum-power point location.
  Change these to move the fake PV curve and watch MPPT respond.

SW3-SW5:
  Simulated irradiance/current level.
  Higher value means more available current and power.

SW7:
  Demo fault input.
  1 forces the protection flag.
```

LED behavior
------------

```text
LD0:
  PWM output.

LD1:
  Telemetry heartbeat.

LD2:
  UART busy.

LD3:
  Fault/protection flag.

LD4:
  Current MPPT perturb direction.

LD5-LD7:
  SW0-SW2 maximum-power-point selector.
```

Expected packet shape
---------------------

```text
p3,seq=00001,d_pct=00012,v_mv=11640,i_ma=00960,p_mw=11174,mppt=up,f=0,chk=XX,raw=20
```

The values will change automatically as the FPGA searches around the simulated
maximum-power point.

Pass condition
--------------

```text
1. Bitstream programs successfully.
2. COM6 receives valid p3 packets.
3. Dashboard shows duty changing without manually moving SW0-SW7 as duty.
4. MPPT Status changes between Power increased, Power decreased, and Hold.
5. Power and duty trend lines move.
6. SW0-SW2 changes move the target point and the controller responds.
7. SW7=1 shows FAULT/protection on the dashboard.
```
