Solar Tracker and BESS Board Test 06: Real Solar Voltage with MCP3208
=====================================================

Status
------

```text
PASS
```

Date
----

```text
2026-07-25
```

Goal
----

Prove that the Nexys Video FPGA can read a real solar-panel voltage through the
MCP3208 SPI ADC and continue sending the same p3 telemetry packet over UART.

Vivado board code
-----------------

```text
Board:
  Digilent Nexys Video 410-316

Vivado part code:
  xc7a200tsbg484-1

Top module:
  solar_real_sense_uart_top

HDL:
  solar-tracker-bess/code/hdl/uart_tx.v
  solar-tracker-bess/code/hdl/mcp3208_reader.v
  solar-tracker-bess/code/hdl/solar_real_sense_uart_top.v

Constraints:
  solar-tracker-bess/hardware/constraints/nexys_video_solar_real_sense_uart.xdc
```

Hardware setup
--------------

```text
Solar panel + -> 100k resistor
100k other side -> CH0 node
CH0 node -> 22k resistor -> GND
CH0 node -> MCP3208 CH0 / pin 1
Solar panel - -> GND

MCP3208 CH1 / pin 2 -> GND
```

MCP3208 SPI:

```text
CS/SHDN -> Nexys Video JB1
DIN     -> Nexys Video JB2
DOUT    -> Nexys Video JB3
CLK     -> Nexys Video JB4
VDD     -> Pmod 3.3V
VREF    -> Pmod 3.3V
AGND    -> Pmod GND
DGND    -> Pmod GND
```

Notes
-----

```text
The reported current is near zero because CH1 is tied to GND.
The reported power is therefore near zero until real current sensing is added.
Voltage jumps are expected during hand shadowing, moving light, or temporary
no-solder solar-panel contact.
```
