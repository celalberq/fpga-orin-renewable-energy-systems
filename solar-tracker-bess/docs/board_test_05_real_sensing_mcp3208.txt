Solar Tracker and BESS Board Test 05: MCP3208 Real Voltage/Current Sensing
===========================================================

Status
------

```text
READY FOR VIVADO BUILD / BOARD TEST PENDING UNTIL MCP3208 IS CONNECTED
```

Goal
----

Read real analog values through MCP3208 and stream them through the same p3
UART packet used by the existing UDP gateway and dashboard.

Vivado board code
-----------------

```text
Board:
  Digilent Nexys Video 410-316

Vivado part code:
  xc7a200tsbg484-1

Top module:
  solar_real_sense_uart_top

HDL sources:
  solar-tracker-bess/code/hdl/uart_tx.v
  solar-tracker-bess/code/hdl/mcp3208_reader.v
  solar-tracker-bess/code/hdl/solar_real_sense_uart_top.v

Constraints:
  solar-tracker-bess/hardware/constraints/nexys_video_solar_real_sense_uart.xdc
```

Vivado steps
------------

```text
1. Create/open a Vivado RTL project.
2. Select part:
     xc7a200tsbg484-1
3. Add HDL sources:
     uart_tx.v
     mcp3208_reader.v
     solar_real_sense_uart_top.v
4. Add constraints:
     nexys_video_solar_real_sense_uart.xdc
5. Set top:
     solar_real_sense_uart_top
6. Run Synthesis.
7. Run Implementation.
8. Generate Bitstream.
9. Program Device.
```

MCP3208 wiring on Pmod JB
-------------------------

```text
JB1/V9 -> MCP3208 CS/SHDN
JB2/V8 -> MCP3208 DIN
JB3/V7 -> MCP3208 DOUT
JB4/W7 -> MCP3208 CLK
3.3V  -> MCP3208 VDD and VREF
GND   -> MCP3208 AGND and DGND
```

ADC channels
------------

```text
CH0:
  voltage divider output

CH1:
  analog current-sense output or safe 0V-3.3V test signal
```

First safe input test
---------------------

```text
1. Leave real solar/battery disconnected.
2. Feed CH0 from a safe divider output.
3. Feed CH1 from GND first.
4. Program the FPGA.
5. Confirm p3 packets still pass checksum.
6. Change CH0 input slowly and confirm v_mv changes.
7. Change CH1 test signal slowly and confirm i_ma changes.
```

Expected packet shape
---------------------

```text
p3,seq=00001,d_pct=00012,v_mv=01234,i_ma=00000,p_mw=00000,mppt=up,f=0,chk=XX,raw=20
```

Pass condition
--------------

```text
1. Bitstream programs successfully.
2. UART receives p3 packets.
3. Gateway prints OK.
4. Dashboard link health stays healthy.
5. v_mv changes with CH0.
6. i_ma changes with CH1.
7. f=1 appears if SW7 is on or measured limits exceed the protection threshold.
```
