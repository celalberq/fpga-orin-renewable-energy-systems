Fast-Track Execution Plan
=========================

Reason
------

The careful one-by-one FPGA tests were useful for confidence, but the project now
needs bigger integrated milestones.

New rule
--------

```text
Do not spend every step on a tiny isolated board proof.

Use board tests only when they unlock a bigger system layer.
Group the work into integrated demos that connect solar-tracker-bess, fpga-digital-communications, and network-telemetry-dashboard.
```

Milestone A: Integrated Solar Telemetry Network Demo
----------------------------------------------------

```text
Input:
  solar-tracker-bess p3 solar packet from Nexys Video UART

PC/Orin-style gateway:
  validate checksum
  check sequence gaps
  convert to JSON
  send UDP packet
  log CSV

Network side:
  receive UDP JSON
  log CSV
  print status

Status:
  CREATED
```

Files:

```text
network-telemetry-dashboard/code/pc_app/solar_telemetry_udp_gateway.py
network-telemetry-dashboard/code/pc_app/solar_telemetry_udp_receiver.py
network-telemetry-dashboard/code/pc_app/solar_live_dashboard.py
network-telemetry-dashboard/docs/network_test_01_solar_udp_gateway.txt
network-telemetry-dashboard/docs/network_test_02_live_dashboard.txt
```

Milestone B: Integrated Reliability Demo
----------------------------------------

```text
Input:
  same p3 solar packet

fpga-digital-communications:
  wrap packet with communication metadata
  simulate QPSK/OFDM reliability
  report CRC/BER/frame error results

network-telemetry-dashboard:
  forward the result as network JSON
```
