Three-Project Basic Build Plan
==============================

Purpose:

This stage is not board bring-up and not HDL/Python coding yet. It defines the basic build path for the three projects so the later code part is organized.

Common format:

```text
We do this
Add these
This will achieve
Then code part
```

Shared build direction:

```text
FPGA board:
  Digilent Nexys Video 410-316

Temporary software side:
  Laptop/PC first

Later software side:
  Jetson Orin Nano Super

Current work:
  define basic project structure, build blocks, data flow, module names, and deliverables

Later work:
  implement HDL, simulations, PC scripts, then Orin integration
```

Project order:

```text
1. solar-tracker-bess solar renewable energy
   Main computer + renewable portfolio project.

2. fpga-digital-communications digital communication
   Strong support for FPGA/DSP, telemetry, and reliable data movement.

3. network-telemetry-dashboard network
   Basic support for Ethernet literacy and infrastructure monitoring.
```

Common basic build outputs:

```text
1. Clear block list
2. Required external parts
3. FPGA module list
4. PC/Orin software module list
5. Data/telemetry fields
6. First code files to create later
7. Final demo target
```

Common later code layout:

```text
project/
  code/
    hdl/
      FPGA modules
    sim/
      HDL and Python simulations
    pc_app/
      temporary PC-side scripts
    tests/
      expected inputs/outputs and small verification files
```

Important rule:

Each project should have a small successful first version before adding expensive peripherals or complex AI.
