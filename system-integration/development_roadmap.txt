Development Roadmap
===================

Goal:

Build three organized summer projects around a Nexys Video FPGA, Jetson Orin
Nano, and PC dashboard, then integrate them as one renewable-energy telemetry
prototype.

Post-graduation alignment:

```text
Main external direction:
  Australia master's applications around computer engineering + renewable energy systems.

Best-facing project:
  solar-tracker-bess Renewable Energy Solar Project, extended toward solar+BESS monitoring, MPPT simulation, and SCADA-style telemetry.

Core technical identity:
  FPGA/embedded/software/data systems applied to renewable energy.

Strong support:
  Digital communication for telemetry, signal processing, and reliable data movement.

Basic support:
  Networking for Ethernet literacy and infrastructure monitoring.
```

Recommended build order:

```text
Phase 0: Documentation and platform setup
Phase 1: Nexys Video bring-up and UART telemetry
Phase 2: Shared renewable telemetry packet on FPGA
Phase 3: PC parser/logger for shared packet
Phase 4: solar-tracker-bess MPPT fake-control and then real sensor path
Phase 5: fpga-digital-communications digital communication reliability layer using the same packet
Phase 6: network-telemetry-dashboard network transport/parsing layer using the same packet
Phase 7: Orin Nano Super dashboard/logging/AI supervisor
Phase 8: Turn each layer into demo, report, and CV artifact
```

Why this order:

```text
Solar first:
  It is the best Australia-facing project and has a safe low-voltage MVP.

Digital communication second:
  It strengthens the computer/FPGA side with DSP, modulation, and telemetry fundamentals.

Network third:
  It is useful as basic infrastructure literacy, but it should not become the main identity.
```
