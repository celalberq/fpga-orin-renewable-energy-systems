Historical recommendation logic:

```text
Best technical board if available:
  Nexys Video

Best practical board if keeping pure FPGA + Orin architecture:
  Arty A7-100T

Best network-focused board:
  Zybo Z7-20

Avoid as the main shared board:
  Basys 3, because no onboard Ethernet
```

Original decision rule:

```text
If network-telemetry-dashboard must be serious network hardware:
  prioritize Gigabit Ethernet.

If network-telemetry-dashboard can be monitor-mode at 10/100 Mbps:
  Arty A7-100T becomes a strong practical choice.

If Turkey availability is poor:
  do not overfit to one board; buy the best available board that satisfies Ethernet + expansion + DSP requirements.
```
