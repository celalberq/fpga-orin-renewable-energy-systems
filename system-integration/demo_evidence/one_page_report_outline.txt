One Page Report Outline
=======================

Use this as the first written report version. Keep it to one page first; expand
only after the one-page version is strong.

Title
-----

```text
FPGA and Jetson Orin Based Solar Tracker Telemetry Platform with
CRC/QPSK/OFDM Communication Profiling and UDP Monitoring
```

1. Problem
----------

```text
Renewable-energy systems need reliable real-time sensing, local control, and
networked monitoring. A small solar tracker is a useful low-voltage prototype
because it connects PV measurement, embedded control, communication reliability,
and SCADA-style observability.
```

2. System Architecture
----------------------

```text
solar-tracker-bess Orin tracker/INA226 sensor/mounted panel
  -> UDP tracker telemetry
  -> fpga-digital-communications digital communication bridge
  -> CRC/QPSK/OFDM profile
  -> network-telemetry-dashboard live dashboard
```

Hardware:

```text
Nexys Video FPGA:
  deterministic packet/communication proof, CRC, QPSK/OFDM counters, UART.

Jetson Orin Nano:
  Linux edge gateway, I2C sensing, tracker loop, pan/tilt servo control,
  UDP telemetry.

PC:
  dashboard, logging, bridge, evidence generation.
```

3. Implementation
-----------------

```text
Renewable layer:
  INA226 sensing, software tracker state, pan/tilt mounted panel actuation,
  BESS model, panel voltage/current/power.

Digital communication layer:
  compact ASCII tracker payload, CRC-8 frame, QPSK symbols, OFDM resource grid,
  pilot/null/padding/CP accounting.

Network layer:
  UDP gateway, bridge forwarding, sequence-gap detection, invalid packet counter,
  live dashboard and CSV logging.
```

5. Limitations
--------------

```text
The current physical panel mount is prototype-grade: a cardboard adapter/base
with elastic-band stabilization. It is usable for demonstrating pan/tilt tracker
actuation, but the final video should avoid overclaiming mechanical polish.
Indoor light also gives low INA226 solar power readings, so stronger light or
sunlight is needed for better power plots.
```

6. Why It Matters
-----------------

```text
The project demonstrates a computer engineering plus renewable energy direction:
embedded sensing, FPGA communication validation, networked telemetry, dashboard
monitoring, and reportable system evidence. It connects renewable-energy
hardware with digital communication and network observability rather than
showing three unrelated lab demos.
```
