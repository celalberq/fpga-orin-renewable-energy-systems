Demo Talking Points
-------------------

```text
This is one system split into three engineering layers.

solar-tracker-bess is the renewable-energy layer:
  tracker state, solar sensing, INA226, Orin edge gateway.

fpga-digital-communications is the communication reliability layer:
  CRC frame, QPSK symbol mapping, OFDM packet sizing, FPGA validation.

network-telemetry-dashboard is the network monitoring layer:
  UDP transport, packet validation, gap detection, live dashboard.
```

If Something Fails
------------------

```text
Dashboard does not update:
  Check that bridge is forwarding to port 5011.
  Check browser is on http://127.0.0.1:8085.

Bridge does not print:
  Check Orin gateway is sending to PC IP and port 5013.
  Check PC firewall if needed.

INA226 reads zero:
  This can be normal indoors with weak light.
  Use a stronger light or sunlight for power plots.

Digital Comm Layer says raw UDP:
  Orin is probably sending directly to dashboard instead of through the bridge.
  Correct path is Orin -> port 5013 bridge -> port 5011 dashboard.
```
