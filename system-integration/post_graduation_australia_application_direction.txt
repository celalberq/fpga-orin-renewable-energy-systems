
```text

Avoid making the main career target:
  - RF hardware design
  - antenna/electromagnetic field design

Do not avoid electrical engineering completely.
Aim for computer/embedded renewable systems: system-level power, renewables, controls, BESS, SCADA, data, telemetry, and grid integration.
```

University and Program Selection Rules
--------------------------------------

Do not choose mainly by QS rank. Use this order:

```text
1. Engineers Australia accreditation or a clear Washington Accord/professional recognition path
2. Course content fit: power systems, renewable energy, grid integration, BESS, control, SCADA, embedded systems
3. Industry connection, placement, capstone, internship, or practical project structure
4. Location fit, especially Melbourne if using the EMMS network
5. Cost, scholarship chance, visa timeline, and living logistics
6. Ranking as a supporting factor, not the main decision
```

EMMS Network Action Plan
------------------------

The EMMS connection should be used carefully and professionally.

Goal:

```text
Get advice first. Do not ask directly for a job in the first message.
```

Message angle:

```text
I am preparing for a master's in Australia and I am interested in utility-scale solar, BESS, grid integration, and EPC/project engineering. I am building a small renewable energy/FPGA portfolio and would really value 20-30 minutes of advice about which skills junior engineers should build before coming to Australia.
```

Questions to ask:

```text
1. For a new graduate, which path is more realistic: project engineer, grid connection, SCADA/commissioning, or asset performance?
2. Which software/tools matter most for junior renewable engineers in Australia?
3. What should I learn before arriving: PowerFactory, PSCAD, PSS/E, PVsyst, Python, MATLAB, AutoCAD, project management, or something else?
4. What makes a master's student employable while studying?
5. Would a small solar+BESS monitoring project be useful as a portfolio piece?
6. Could he review a 1-page CV/portfolio later, after it is polished?
```

Do before the call:

```text
1. Prepare a 1-page CV.
2. Prepare a 1-page project portfolio summary.
3. Have a clean explanation of why renewables fit you.
4. Do not overclaim technical depth.
```
