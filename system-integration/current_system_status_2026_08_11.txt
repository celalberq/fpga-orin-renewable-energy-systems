Current System Status - 2026-08-11
==================================

High-Level Result
-----------------

The three project layers now operate as one live renewable-energy tracker and
storage telemetry prototype.

```text
solar-tracker-bess renewable layer:
  Four KY-018 sensors -> MCP3208 -> Nexys Video UART -> Jetson Orin tracker
  PCA9685 drives real pan and tilt servos carrying the prototype solar panel
  MCP3208 CH0 measures panel voltage across a known 1k-ohm load
  INA226 measures protected 1S battery voltage and signed charge/discharge current

fpga-digital-communications communication layer:
  Mixed tracker/panel/BESS payload -> CRC frame -> QPSK/OFDM profile
  Live unified frame: 157-byte payload, 161-byte frame, 644 QPSK symbols,
  14 OFDM symbols, 28 padding symbols

network-telemetry-dashboard network layer:
  UDP forwarding -> packet/gap validation -> live dashboard -> CSV evidence
```

Safety And Honest Limitations
-----------------------------

```text
The Orin and Nexys remain on their normal external supplies.
The battery does not power the Orin or Nexys.
The TP4056 USB input is disconnected while the fan load is connected.
Temporary battery connections are for supervised bench testing only.
The panel-power values are low indoor measurements from a handheld LED.
The tracker mechanics and sensor cross are functional prototype construction.
The communication layer is CRC/QPSK/OFDM profiling and FPGA pipeline proof,
not a complete over-the-air RF modem.
```
