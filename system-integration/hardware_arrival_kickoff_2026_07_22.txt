First physical test: MCP3208 CH0 voltage
----------------------------------------

Goal:

```text
Prove that the FPGA reads a real analog voltage through MCP3208 and reports it
through the same p3 UART -> UDP -> dashboard path.
```

MCP3208 DIP-16 wiring:

```text
MCP3208 pin 16 VDD  -> Nexys/Pmod 3.3V
MCP3208 pin 15 VREF -> Nexys/Pmod 3.3V
MCP3208 pin 14 AGND -> Nexys/Pmod GND
MCP3208 pin 9  DGND -> Nexys/Pmod GND

MCP3208 pin 10 CS/SHDN -> Nexys Video JB1 / adc_cs_n
MCP3208 pin 11 DIN     -> Nexys Video JB2 / adc_mosi
MCP3208 pin 12 DOUT    -> Nexys Video JB3 / adc_miso
MCP3208 pin 13 CLK     -> Nexys Video JB4 / adc_sclk

MCP3208 pin 1 CH0 -> voltage divider midpoint
MCP3208 pin 2 CH1 -> GND for the first test so current does not float
```

Pmod JB signal mapping:

```text
JB1 = adc_cs_n
JB2 = adc_mosi
JB3 = adc_miso
JB4 = adc_sclk
```

Voltage divider for CH0:

```text
Input voltage + -> 100k -> CH0 midpoint -> 22k -> GND
```

Expected safe first test:

```text
Use Nexys 3.3V as the divider input.
CH0 midpoint should measure about 0.60 V with the multimeter.
UART v_mv should report roughly 3300 mV after FPGA scaling.
```

Do not connect CH0 until the multimeter confirms:

```text
CH0 midpoint <= 3.3 V
```

Current placeholder
-------------------

For the first test:

```text
CH1 tied to GND means i_ma should be near 00000.
p_mw should stay near 00000 because current is near zero.
This is fine; this first test is only proving real voltage sensing.
```

After CH0 passes:

```text
Use a safe 0V-3.3V signal on CH1.
Then move to INA226 calibration for real panel current/power.
```

Storage/fan safety
------------------

```text
Battery -> fuse -> MT3608 boost -> fan/load.
Nexys/Orin only observe through sensors/dividers.

Initial discharge policy:
  SoC > 80%: allow fan discharge.
  SoC < 50%: stop fan discharge.
  battery < 3.3V: hard low-voltage warning.
  battery near 3.0V: stop testing.
```
