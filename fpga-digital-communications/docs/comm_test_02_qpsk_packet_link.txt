FPGA Digital Communications Communication Test 02: QPSK Packet Link Simulation
=========================================================

Goal
----

Add the first modulation layer under the same shared renewable telemetry packet.

This test takes the framed `p3` payload from Test 01, maps its bits to QPSK symbols,
adds AWGN noise, demaps the symbols, reconstructs the frame, and checks CRC/frame
validity.

Board / Vivado code
-------------------

```text
Board:
  Digilent Nexys Video 410-316

Vivado part code:
  xc7a200tsbg484-1
```

This test is simulation-only. FPGA QPSK HDL comes after the packet-level QPSK behavior
is understood.

Input frame
-----------

```text
preamble:
  0xA5 0x5A

length:
  0x53

payload:
  shared p3 renewable telemetry packet

crc:
  CRC-8 polynomial 0x07 over length + payload
```

QPSK mapping
------------

```text
00 -> I=+1, Q=+1
01 -> I=-1, Q=+1
11 -> I=-1, Q=-1
10 -> I=+1, Q=-1
```

Script
------

```text
fpga-digital-communications/code/sim/qpsk_packet_link_sim.py
```

Run:

```text
python fpga-digital-communications/code/sim/qpsk_packet_link_sim.py
```

Outputs:

```text
fpga-digital-communications/data/qpsk_packet_link_sim.csv
fpga-digital-communications/data/qpsk_packet_link_constellation.csv
```

Metrics
-------

```text
ebn0_db:
  Simulated energy-per-bit to noise-density ratio.

ber:
  Bit error rate after QPSK demapping.

fer:
  Frame error rate after reconstructing the frame and checking preamble/length/CRC.

crc_detected_errors:
  Corrupted frames rejected by the receiver.

undetected_errors:
  Corrupted frames that still passed frame checks.
```

Pass condition
--------------

```text
1. Simulation runs.
2. CSV outputs are generated.
3. BER decreases as Eb/N0 increases.
4. FER decreases as Eb/N0 increases.
5. High Eb/N0 reaches zero or near-zero frame errors.
6. The shared p3 telemetry frame remains the payload.
```

Result
------

```text
PASS
```
