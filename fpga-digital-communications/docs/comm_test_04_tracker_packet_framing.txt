FPGA Digital Communications Communication Test 04: Tracker Packet Framing and CRC
=============================================================

Status
------

```text
PASS
```

Goal
----

Upgrade the digital communication payload from the older compact `p3` solar
packet to the newer Orin tracker/INA226 packet.

This keeps fpga-digital-communications aligned with the current integrated system:

```text
solar-tracker-bess: software tracker + INA226 sensing
network-telemetry-dashboard: UDP dashboard + reliability proxy
fpga-digital-communications: framing, CRC, QPSK, and OFDM protection for that same telemetry
```

Payload profile
---------------

Example:

```text
trk,seq=00023,pan=124.9,tilt=102.6,sun_pan=127.0,sun_tilt=102.8,err=002.1,st=lock,v_mv=05506,i_ma=00421,p_mw=02318,src=ina,act=sw
```

Frame format
------------

```text
preamble:
  0xA5 0x5A

length:
  1 byte payload length

payload:
  ASCII tracker telemetry packet

crc:
  CRC-8 over length + payload
```
