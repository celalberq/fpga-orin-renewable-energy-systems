Goal
----

Run the current tracker/INA226 telemetry packet through the OFDM packet-link
model.

OFDM parameters
---------------

```text
frame_bytes:
  133

  1064

  64

  16 samples

  48

Pilot subcarriers:
  4

OFDM symbols per packet:
  12

  88 bits
```

Interpretation
--------------

```text
The tracker frame needs 12 OFDM symbols instead of the old 8-symbol p3 packet.
That affects future FPGA resource-grid counters and packet scheduling.
The BER/FER curve still behaves correctly and reaches zero errors at high Eb/N0.
```
