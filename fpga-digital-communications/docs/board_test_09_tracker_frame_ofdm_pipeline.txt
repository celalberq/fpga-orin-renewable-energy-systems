FPGA Digital Communications Board Test 09: Tracker Frame + OFDM Pipeline
===================================================

Goal
----

Combine the two passing FPGA proofs:

```text
1. Tracker frame encoder and CRC-8 generation.
2. Tracker OFDM payload placement counters.
```

This proves that the Nexys Video can take the compact tracker payload shape,
build the protected frame profile, and then account for the QPSK/OFDM transmission
structure in one board design.

Vivado board code
-----------------

```text
Board:
  Digilent Nexys Video 410-316

Vivado part code:
  xc7a200tsbg484-1

Top module:
  tracker_frame_ofdm_pipeline_top

HDL sources:
  fpga-digital-communications/code/hdl/uart_tx.v
  fpga-digital-communications/code/hdl/crc8_byte.v
  fpga-digital-communications/code/hdl/tracker_payload_rom.v
  fpga-digital-communications/code/hdl/tracker_frame_ofdm_pipeline_top.v

Constraints:
  fpga-digital-communications/hardware/constraints/nexys_video_tracker_frame_ofdm_pipeline.xdc
```

Expected UART report
--------------------

```text
p1pipe,seq=00001,pay_b=00129,frame_b=00133,crc=XX,crc_ok=1,ofdm=012,tx_s=00960,cp_s=00192,payload=00532,pad_q=00044,ok=1
```

Notes:

```text
crc changes when seq changes, so do not expect a fixed crc value.
crc_ok=1 and ok=1 are the pass indicators.
```

Expected values
---------------

```text
pay_b:
  00129

frame_b:
  00133

ofdm:
  012

tx_s:
  00960

cp_s:
  00192

payload:
  00532 QPSK symbols

pad_q:
  00044 QPSK symbols
```

LED behavior
------------

```text
LD0:
  CRC OK.

LD1:
  Heartbeat toggles once per report.

LD2:
  UART busy.

LD3:
  CRC/OFDM pipeline running.

LD4-LD7:
  Fixed 1001 marker for tracker frame + OFDM pipeline.
```

UART
----

```text
Connector:
  J13

PC port:
  Usually COM6, but confirm in Windows Device Manager.

Baud:
  115200

Data:
  8 data bits, no parity, 1 stop bit, flow control none
```

Pass condition
--------------

```text
1. Bitstream programs successfully.
2. PuTTY/TeraTerm receives p1pipe lines on the J13 UART COM port.
3. seq increments once per report.
4. pay_b=00129 and frame_b=00133.
5. crc is two hex characters and crc_ok=1.
6. ofdm=012, tx_s=00960, cp_s=00192.
7. payload=00532 and pad_q=00044.
8. ok=1.
```
