FPGA Digital Communications Board Test 06: Tracker OFDM Resource-Grid Counter
========================================================

Goal
----

Move the digital communication model from the old basic `p3` packet to the larger
tracker telemetry packet used by the Orin software tracker and real INA226 solar
sensor path.

This is still a safe FPGA stepping stone before a full FFT/IFFT modem. The Nexys
Video reports the packet accounting that the QPSK/OFDM layer must support:
tracker frame size, QPSK symbols, OFDM symbols, cyclic prefix, pilot/data carriers,
and padding.

Tracker OFDM parameters
-----------------------

```text
Tracker frame:
  133 bytes / 1064 bits

QPSK symbols:
  532

FFT size:
  64

Cyclic prefix:
  16 samples

Data subcarriers:
  48

Pilot subcarriers:
  4

OFDM symbols per packet:
  12

Padding:
  88 bits
```

LED behavior
------------

```text
LD0:
  Constant OK.

LD1:
  Heartbeat toggles once per report.

LD2:
  UART busy.

LD4-LD7:
  Fixed 0110 marker for tracker OFDM board test.
```

UART
----

```text
Connector:
  J13

PC port:
  Usually COM6, but confirm in Windows Device Manager.

Baud:
  115200

Data:
  8 data bits, no parity, 1 stop bit, flow control none
```

Expected output
---------------

```text
p1ot,seq=00001,frame_b=00133,bits=01064,qpsk=00532,fft=064,cp=016,data=048,pilot=004,ofdm=012,pad=00088,ok=1
```

Pass condition
--------------

```text
1. Bitstream programs successfully.
2. PuTTY/TeraTerm receives p1ot lines on the J13 UART COM port.
3. seq increments once per report.
4. frame_b=00133, bits=01064, qpsk=00532.
5. fft=064, cp=016, data=048, pilot=004, ofdm=012, pad=00088.
6. ok=1.
```

Result
------

```text
PASS
```

Observed output:

```text
p1ot,seq=00031,frame_b=00133,bits=01064,qpsk=00532,fft=064,cp=016,data=048,pilot=004,ofdm=012,pad=00088,ok=1
p1ot,seq=00032,frame_b=00133,bits=01064,qpsk=00532,fft=064,cp=016,data=048,pilot=004,ofdm=012,pad=00088,ok=1
```

Confirmed:

```text
seq increments once per report.
frame_b=00133 and bits=01064 match the tracker telemetry frame.
qpsk=00532 and pad=00088 match the tracker OFDM simulation.
fft=064, cp=016, data=048, pilot=004, ofdm=012 are correct.
ok=1.
```

Why this matters
----------------

```text
This connects the real renewable-energy tracker packet to the digital
communication layer:
  Orin tracker telemetry -> packet framing -> QPSK symbol count -> OFDM resource grid

After this passes on Nexys, the next useful board step is an OFDM payload placer
that walks symbol/subcarrier indices and marks data, pilot, padding, and cyclic
prefix regions.
```
