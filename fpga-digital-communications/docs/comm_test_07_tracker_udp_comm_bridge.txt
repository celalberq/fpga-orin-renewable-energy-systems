FPGA Digital Communications Comm Test 07: Live Tracker UDP to Digital-Comm Frame Bridge
=================================================================

Goal
----

Connect the live renewable-energy tracker path to the digital communication
packet profile.

This test receives rich Orin tracker JSON from `solar-tracker-bess`, converts it into the
compact ASCII tracker payload used by `fpga-digital-communications`, wraps it with the shared frame
format, computes QPSK/OFDM packet counts, logs the result, and forwards the
original JSON to the `network-telemetry-dashboard` dashboard.

Why two packet forms exist
--------------------------

```text
Rich JSON:
  Used by network-telemetry-dashboard dashboard/network monitoring.
  Easy for PC/Orin software to parse and extend.

Compact ASCII frame:
  Used by fpga-digital-communications digital communication.
  Fixed-size, CRC-protected, and easy to map into QPSK/OFDM.
```

Run order
---------

PC terminal 1, dashboard:

```text
cd "<repository-root>"
python network-telemetry-dashboard/code/pc_app/solar_live_dashboard.py --udp-host 0.0.0.0 --udp-port 5011 --http-host 127.0.0.1 --http-port 8085 --bess-load-w 0.1
```

PC terminal 2, bridge:

```text
cd "<repository-root>"
python fpga-digital-communications/code/pc_app/tracker_udp_comm_bridge.py --bind-host 0.0.0.0 --bind-port 5013 --forward-host 127.0.0.1 --forward-port 5011
```

Orin terminal, tracker gateway:

```text
cd /home/msi
python3 solar-tracker-bess/code/orin_app/tracker_softloop_udp_gateway.py --udp-host PC_IP_ADDRESS --udp-port 5013 --lock-error-deg 10 --ina-enable --ina-bus 7 --ina-addr 0x44 --shunt-ohms 0.1
```

Replace:

```text
PC_IP_ADDRESS:
  Your Windows PC IP address, for example 192.168.1.219.
```

Expected bridge output
----------------------

```text
OK from=192.168.1.30:xxxxx p1br,seq=00023,frame_b=00133,bits=01064,qpsk=00532,ofdm=012,pad_q=00044,gap=0,ok=1
```

Expected dashboard behavior
---------------------------

```text
Dashboard still shows the live tracker JSON because the bridge forwards the
original UDP packet to port 5011.
```

Expected compact frame
----------------------

```text
trk,seq=00023,pan=124.9,tilt=102.6,sun_pan=127.0,sun_tilt=102.8,err=002.1,st=lock,v_mv=05506,i_ma=00421,p_mw=02318,src=ina,act=sw
```

Frame and OFDM profile
----------------------

```text
payload bytes:
  129

frame bytes:
  133

frame bits:
  1064

QPSK symbols:
  532

OFDM symbols:
  12

QPSK padding:
  44 symbols
```

Pass condition
--------------

```text
1. Bridge receives Orin tracker UDP JSON.
2. Bridge prints p1br lines with frame_b=00133.
3. bits=01064, qpsk=00532, ofdm=012, pad_q=00044.
4. gap=0 during normal streaming.
5. ok=1.
6. Dashboard still updates through forwarded JSON.
```
