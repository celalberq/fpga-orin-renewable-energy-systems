Project title:

FPGA-Accelerated Adaptive OFDM Communication Link with Orin-Based Link Monitoring

Original main goal:

Design and demonstrate a digital communication reliability layer for the shared renewable telemetry packet, where the FPGA handles real-time framing/baseband work and the Orin Nano Super handles experiment control, visualization, logging, and optional AI-based adaptation.

Original target architecture:

```text
Shared solar-tracker-bess renewable telemetry packet
  -> frame builder
  -> CRC/checksum
  -> FPGA transmitter
  -> digital modulation later
  -> OFDM framing
  -> DAC / PWM-DAC / simulated channel / optional RF front-end
  -> ADC / digital loopback
  -> FPGA receiver
  -> link metrics
  -> Orin Nano dashboard and logging
```

Original planned FPGA role:

```text
1. Bit generation or packet input.
2. QPSK and 16-QAM mapping.
3. OFDM frame creation.
4. IFFT/FFT or staged FFT core.
5. Cyclic prefix insertion and removal.
6. Pilot insertion and channel estimation.
7. BER, packet error, and EVM-style metric calculation.
8. Telemetry streaming to Orin.
```

Original planned Orin Nano role:

```text
1. Dashboard for BER, SNR estimate, packet rate, and constellation plots.
2. Experiment control.
3. CSV/JSON logging.
4. Optional AI model that predicts the best modulation mode.
5. Report plots and demo visuals.
```

Original MVP scope:

```text
1. Start with digital loopback inside FPGA.
2. Add noise/channel model in FPGA or Orin simulation.
3. Add ADC/DAC loopback if hardware is available.
4. Add RF front-end only after baseband works.
```

Original success metrics:

```text
1. QPSK link runs end to end.
2. Receiver recovers packets and calculates BER.
3. Orin dashboard displays live metrics.
4. At least two channel conditions are tested.
5. Final demo compares fixed modulation and adaptive modulation.
```

CV value:

This project demonstrates communication theory, reliable telemetry transfer, real-time FPGA signal processing, embedded AI monitoring, and hardware/software co-design.
