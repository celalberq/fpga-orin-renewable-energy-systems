Basic Build Plan: fpga-digital-communications Digital Communication
==============================================

Project:

FPGA-Accelerated Adaptive OFDM Communication Link with PC/Orin Link Monitoring

Goal of this basic build:

Build the digital communication layer around the shared renewable telemetry packet.

We do this:

```text
1. Use the shared solar-tracker-bess telemetry packet as payload.
2. Add digital communication framing.
3. Add CRC-8 for error detection.
4. Simulate bit errors and frame errors.
5. Later add QPSK before OFDM.
6. Use internal FPGA-style loopback as the first board version.
```

Add these:

```text
Design blocks:
  - shared telemetry packet payload
  - frame builder
  - CRC-8 generator
  - controlled channel/error model
  - frame checker
  - QPSK mapper
  - channel/loopback placeholder
  - QPSK demapper
  - packet checker
  - BER/error counter
  - telemetry output

Telemetry fields:
  - project name
  - modulation mode
  - packet count
  - bit count
  - error count
  - BER
  - link status

Folders already prepared:
  - code/hdl
  - code/sim
  - code/pc_app
  - code/tests
  - hardware/constraints
  - hardware/pin_maps
```

This will achieve:

```text
1. A clean first communication prototype that does not depend on RF hardware.
2. A measurable result through BER and packet counters.
3. A strong base for OFDM later.
4. A path where PC scripts can later move to Orin.
5. A portfolio story showing FPGA DSP and communication design.
```

Not included in first version:

```text
1. SDR
2. RF transmitter/receiver
3. External ADC/DAC
4. Full OFDM
5. AI adaptive modulation
```
