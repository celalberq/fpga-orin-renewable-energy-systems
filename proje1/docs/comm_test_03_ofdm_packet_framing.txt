Proje1 Communication Test 03: OFDM Packet Framing Simulation
============================================================

Goal
----

Move from single-carrier QPSK to the first OFDM packet model while keeping the same
shared renewable telemetry frame.

This test takes the framed `p3` packet, maps bits to QPSK symbols, places those symbols
into OFDM data subcarriers, inserts pilots, adds a cyclic prefix, applies AWGN, removes
the cyclic prefix, FFTs back to subcarriers, demaps QPSK, reconstructs the frame, and
checks CRC/frame validity.

Board / Vivado code
-------------------

```text
Board:
  Digilent Nexys Video 410-316

Vivado part code:
  xc7a200tsbg484-1
```

This test is simulation-only. FPGA OFDM HDL comes after the resource grid and packet
framing behavior are stable.

OFDM parameters
---------------

```text
FFT size:
  64

Cyclic prefix:
  16 samples

Active subcarriers:
  -26..-1 and +1..+26

Pilot subcarriers:
  -21, -7, +7, +21

Data subcarriers:
  48

Payload frame:
  87 bytes / 696 bits

QPSK symbols from frame:
  348

OFDM symbols per packet:
  8

Padding:
  72 bits
```

Metrics
-------

```text
ber:
  Bit error rate after OFDM receive and QPSK demapping.

fer:
  Frame error rate after reconstructing the packet and checking preamble/length/CRC.

crc_detected_errors:
  Corrupted frames rejected by the receiver.

undetected_errors:
  Corrupted frames that still passed frame checks.
```

Pass condition
--------------

```text
1. Simulation runs.
2. CSV outputs are generated.
3. Resource grid output shows data and pilot carriers.
4. BER decreases as Eb/N0 increases.
5. FER collapses toward zero as Eb/N0 increases.
6. High Eb/N0 reaches zero or near-zero frame errors.
7. The shared p3 telemetry frame remains the payload.
```

Result
------

```text
PASS
```

Theory note:

```text
FER can stay high even after BER starts dropping because one frame contains 696 bits.
This is why communication systems need both physical-layer BER metrics and packet/CRC
metrics.
```
