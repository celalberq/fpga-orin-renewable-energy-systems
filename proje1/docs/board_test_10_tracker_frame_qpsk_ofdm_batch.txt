Proje1 Board Test 10: Tracker Frame QPSK + OFDM Batch
=====================================================

Goal
----

Move faster by combining the next two digital communication proofs into one
Vivado bitstream:

```text
1. Build the protected tracker frame:
   preamble + length + 129-byte tracker payload + CRC-8.

2. Map all 133 frame bytes into QPSK symbols:
   133 bytes * 8 bits / 2 bits per QPSK symbol = 532 symbols.

3. Place those QPSK symbols into the OFDM stream:
   12 OFDM symbols, 48 data bins and 4 pilot bins per OFDM symbol.
```

Expected UART report
--------------------

```text
p1bat,seq=00001,sym=00532,s00=00168,s01=00134,s11=00146,s10=00084,data=00532,pad=00044,pilot=00048,null=00144,cp=00192,crc=44,ok=1
```

Notes:

```text
crc changes when seq changes.
s00/s01/s11/s10 can change slightly when seq and crc change.

Stable pass indicators:
  sym=00532
  data=00532
  pad=00044
  pilot=00048
  null=00144
  cp=00192
  ok=1
```

Meaning
-------

```text
sym:
  QPSK symbols generated from the protected frame.

s00/s01/s11/s10:
  Count of each QPSK constellation bit-pair category.

data:
  Real tracker-frame QPSK symbols placed into OFDM data bins.

pad:
  Unused OFDM data bins after the 532 payload symbols are placed.

pilot:
  OFDM pilot bins used for synchronization/channel tracking theory.

null:
  Guard/DC/null bins left empty.

cp:
  Cyclic-prefix samples.
```

LED behavior
------------

```text
LD0:
  Full batch OK.

LD1:
  Heartbeat toggles once per report.

LD2:
  UART busy.

LD3:
  CRC/QPSK/OFDM batch running.

LD4-LD7:
  Fixed 1010 marker for tracker QPSK + OFDM batch.
```

UART
----

```text
Connector:
  J13

PC port:
  Usually COM6, but confirm in Windows Device Manager.

Baud:
  115200

Data:
  8 data bits, no parity, 1 stop bit, flow control none
```

Pass condition
--------------

```text
1. Bitstream programs successfully.
2. PuTTY/TeraTerm receives p1bat lines on the J13 UART COM port.
3. seq increments once per report.
4. sym=00532.
5. data=00532 and pad=00044.
6. pilot=00048, null=00144, cp=00192.
7. ok=1.
```
