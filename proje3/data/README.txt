Proje3 Renewable-Control Evidence Data
======================================

This folder contains solar/PWM reference data, LDR calibration and directional
sweeps, fixed-versus-tracking A/B measurements, and transferred Orin tracker
logs.

The final Orin CSV is generated as
`proje3/data/unified_tracker_bess_bidirectional_demo.csv` on the Orin. Matching
PC-side bridge and dashboard records are indexed in `main_layout/demo_evidence`.
