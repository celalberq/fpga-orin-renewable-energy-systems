Proje3 Board Test 22: Real BESS INA226 Discharge
================================================

Date
----

2026-08-11

Purpose
-------

Validate a real protected 1S Li-ion storage path, a small fan load, and signed
INA226 battery telemetry before carrying the BESS packet through the proje1
CRC/QPSK/OFDM bridge and proje2 dashboard.

Validated hardware
------------------

```text
1S ICR18650 cell: 3.7 V nominal, 2500 mAh label
Measured cell voltage before test: approximately 3.57 V
TP4056 USB-C protected 1S charger board
INA226 R100 module: 0.1 ohm, Orin I2C bus 7, address 0x44
L9110 motor/fan module used as the discharge load
MT3608 disconnected from the valid run
```

Validated discharge wiring
---------------------------

```text
Battery holder black -> TP4056 B-
Battery holder red   -> INA226 VIN-
INA226 VIN+          -> TP4056 B+
INA226 VBS           -> INA226 VIN-

TP4056 OUT+ -> fan VCC and fan INA
TP4056 OUT- -> fan GND and fan INB
TP4056 OUT- -> INA226 GND / Orin common ground

Orin pin 1  3.3 V -> INA226 VCC
Orin pin 6  GND   -> INA226 GND
Orin pin 3  SDA   -> INA226 SDA
Orin pin 5  SCL   -> INA226 SCL
```

The orientation intentionally reports positive current while charging and
negative current while discharging.

MT3608 finding
--------------

The MT3608 was adjusted to 4.99-5.00 V with no load. Its input and output
collapsed to approximately 2.4 V with this fan path. The fan still rotated, but
the converter was no longer regulating. The valid discharge capture therefore
used the fan directly from TP4056 OUT+/OUT-. This is a temporary bench load, not
a validated regulated 5 V supply.

INA226 calibration
------------------

The module's bus-voltage result was about 5 percent high compared with the
multimeter. The opt-in calibration used for this specific module is:

```text
--bus-voltage-scale 0.9501
```

The default software scale remains 1.0 for other INA226 modules and old tests.

Valid test command
------------------

Run on Orin with the fan continuously spinning:

```text
cd /home/msi

python3 proje3/code/orin_app/ina226_reader.py \
  --bus 7 --addr 0x44 \
  --shunt-ohms 0.1 \
  --bus-voltage-scale 0.9501 \
  --interval 0.25 --count 40 \
  --log proje3/data/ina226_bess_fan_discharge_valid.csv
```

Result
------

```text
Samples: 40/40 valid
Battery/load voltage: 2952.436 to 2955.999 mV
Discharge current: -231.350 to -230.700 mA
Battery power: -683.722 to -681.348 mW
Direction: negative, as designed for discharge
```

The readings were stable for the complete ten-second capture. This validates
the battery, load, signed shunt measurement, calibrated voltage reading, and
Orin I2C acquisition path.

Safety and limitations
----------------------

```text
The Orin and Nexys stay on their normal external supplies.
TP4056 USB-C remains disconnected during the discharge test.
The fan is disconnected before charging because this TP4056 has no power-path
or load-sharing controller.
Temporary mechanical wire joints must not be used for unattended charging.
Stop if the cell, charger, shunt, wire joints, or fan driver becomes warm,
swells, smells abnormal, or behaves intermittently.
```
