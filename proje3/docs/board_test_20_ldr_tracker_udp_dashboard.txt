Goal
----

Send the working Nexys/MCP3208 four-LDR tracker, real PCA9685 pan/tilt state,
and panel telemetry through the existing three-project live path:

```text
Nexys/MCP3208 LDR UART -> Orin real LDR tracker
  -> UDP JSON port 5013
  -> proje1 CRC/QPSK/OFDM communication bridge
  -> forwarded UDP JSON port 5011
  -> proje2 live dashboard and CSV log
```

Packet Contract
---------------

```text
schema_variant: orin.ldr_tracker.v1
tracker.pan_deg / tilt_deg
tracker.sun_pan_deg / sun_tilt_deg
tracker.track_error_deg / state
tracker.ldr and normalized LDR errors
light_sensor.panel_mv and four raw MCP3208 channels
v_mv / i_ma / p_mw / power_source
```

The indoor weak-light mode uses the known 1k-ohm panel load and reports
`power_source=mcp3208-1000-ohm-load-estimate`. Strong-light tests can omit
`--panel-load-ohms` and use direct INA226 values instead.

  --port /dev/ttyUSB0 \

  --max-packets 20 \
