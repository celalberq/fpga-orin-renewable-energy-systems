Fast-Track Execution Plan
=========================

Reason
------

The careful one-by-one FPGA tests were useful for confidence, but the project now
needs bigger integrated milestones.

New rule
--------

```text
Do not spend every step on a tiny isolated board proof.

Use board tests only when they unlock a bigger system layer.
Group the work into integrated demos that connect proje3, proje1, and proje2.
```

Milestone A: Integrated Solar Telemetry Network Demo
----------------------------------------------------

```text
Input:
  proje3 p3 solar packet from Nexys Video UART

PC/Orin-style gateway:
  validate checksum
  check sequence gaps
  convert to JSON
  send UDP packet
  log CSV

Network side:
  receive UDP JSON
  log CSV
  print status

Status:
  CREATED
```

Files:

```text
proje2/code/pc_app/solar_telemetry_udp_gateway.py
proje2/code/pc_app/solar_telemetry_udp_receiver.py
proje2/code/pc_app/solar_live_dashboard.py
proje2/docs/network_test_01_solar_udp_gateway.txt
proje2/docs/network_test_02_live_dashboard.txt
```
