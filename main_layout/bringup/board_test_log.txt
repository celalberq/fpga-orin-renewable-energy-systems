Next test:

```text
UART hello-world telemetry to PC.
```

UART port finding:

```text
Nexys Video connector J13 appears in Windows as COM6.
Use J13 / COM6 for UART terminal output.
Use the JTAG/PROG connector for Vivado programming.
```

UART pin check:

```text
The UART constraint matches Digilent Nexys-Video-Master.xdc:
  V18 / uart_tx_in  = FT232R TXD into FPGA, so FPGA input
  AA19 / uart_rx_out = FPGA output into FT232R RXD, so FPGA UART TX

For FPGA-to-PC text output, the design must drive uart_rx_out on AA19.
Earlier code incorrectly drove uart_tx_in on V18; that has been corrected.
```

Expected UART result:

```text
project=bringup,board=nexys_video,status=ok
```
