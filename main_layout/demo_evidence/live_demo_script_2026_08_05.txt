Live Demo Script - 2026-08-05
============================

Purpose
-------

Use this when recording or presenting the current integrated prototype.

Core Claim
----------

```text
This system connects renewable-energy tracking telemetry, digital communication
profiling, and network observability in one working pipeline.
```

Demo Path
---------

```text
Orin tracker / INA226 / mounted panel
  -> UDP to PC port 5013
  -> proje1 CRC/QPSK/OFDM bridge
  -> reliability proxy
  -> proje2 live dashboard
```

What To Show
------------

```text
1. Dashboard receiving live packets.
2. Source = Orin software solar tracker.
3. Digital Comm Layer = CRC/QPSK/OFDM.
4. Frame detail = 133B frame | 532 QPSK | 12 OFDM.
5. Mounted panel moving through the pan/tilt servos.
6. Tracker angles and tracking error changing over time.
7. Warning phase during injected drops/corruption.
8. Recovery phase after clean packets resume.
9. Nexys Video UART board test for tracker CRC/QPSK/OFDM batch.
```

Success Criteria
----------------

```text
Healthy clean run:
  dashboard packets valid
  bridge ok=1
  sequence gaps = 0

Reliability run:
  warning appears during injected faults
  invalid packet count increases
  sequence-gap count increases
  later recent window has 0 invalid and 0 gaps
```
