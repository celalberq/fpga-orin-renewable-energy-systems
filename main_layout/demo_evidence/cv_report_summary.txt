CV And Report Summary

Project Title

```text
FPGA and Jetson Orin Solar Tracker + BESS Telemetry Platform with
CRC/QPSK/OFDM Communication Profiling and UDP Dashboard Monitoring
```

Short Abstract
--------------

```text
This project implements an integrated renewable-energy telemetry prototype using
a Jetson Orin Nano, Digilent Nexys Video FPGA, four KY-018 light sensors through
an MCP3208 ADC, PCA9685 pan/tilt servo control for a prototype-mounted solar
panel, UDP network transport, and a live monitoring dashboard.
Real tracker, panel-power, and signed battery telemetry is processed on the
Orin, converted into a compact CRC-protected frame by the digital communication
layer, profiled as QPSK/OFDM traffic, and displayed on a network dashboard with
packet validation, gap detection, tracking state, and measured BESS status. The
Nexys Video validates the key digital-communication frame, QPSK symbol counts,
OFDM symbols, pilots, padding, and cyclic-prefix accounting on real FPGA
hardware.
```

Honest Limitation Statement
---------------------------

```text
The tracker uses real stationary LDR sensing and a working prototype pan/tilt
panel mount. Indoor light is below useful INA226 current resolution, so the
reported A/B gain is a load-power estimate derived from panel voltage across a
known 1k-ohm resistor, not a claim of high solar production. Real battery
charge/discharge power is measured separately by the INA226. Temporary battery
connections are used only for supervised bench tests. The initial approximately
0.63 V INA226 bus value in the continuous demo came from an open monitored path
and is excluded from battery-voltage claims.
```
